RNG MELODY CREATOR
Настольное приложение для Windows · модель 1.0

ЗАПУСК ИЗ ИСХОДНИКОВ

1. Установите Python 3.12 или новее для Windows с компонентом Tcl/Tk.
   https://www.python.org/downloads/windows/
2. Откройте PowerShell в папке проекта. Проверьте Tkinter:
       python -m tkinter
   Закройте появившееся окно. Затем запустите приложение:
       python main.py
   Если ваш установщик настроил команду py, используйте её вместо python.

У приложения нет внешних библиотек времени выполнения. tkinter
отвечает за интерфейс, random и secrets — за источники случайности,
math и array — за синтез, wave — за PCM WAV, winsound — за асинхронное
воспроизведение через Windows. Чистый Python справляется с короткими
WAV, поэтому NumPy устанавливать не нужно.

Если tkinter не запускается, установите или добавьте Tcl/Tk из
дистрибутива Python для Windows. Если Windows отклоняет запуск звука,
проверьте рабочее аудиоустройство и выбранный выход в настройках Windows.
Готовый WAV всё равно можно сохранить.

ИСПОЛЬЗОВАНИЕ

Выберите один источник, длительность от 5 до 10 секунд с шагом 0,5 с
и звучание 8-bit или 16-bit. Нажмите «Сгенерировать мелодию». В режиме
Custom Seed появится запрос текста. Принимаются кириллица, числа,
пунктуация, другие Unicode-символы и пробелы вместе с видимыми знаками.
После генерации откроется статистика и начнётся воспроизведение.
«Остановить» прекращает звук, а «Воспроизвести» запускает его с начала.
«Статистика» возвращает закрытый отчёт. «Сохранить WAV» сохраняет копию
и добавляет её путь в отчёт. При выборе существующего файла Windows
попросит подтвердить замену.

Временный WAV хранится в папке сеанса внутри
%LOCALAPPDATA%\RNG Melody Creator и удаляется при обычном закрытии.
Сохранённые пользователем копии остаются. Seed живёт в памяти сеанса.
Для повтора пользовательской мелодии используйте те же seed, параметры,
версию модели и версию Python. Time Seed в отчёте — целое число, которое
можно передать программно, как показано в тестах.

ПРОВЕРКИ

    python -m unittest -v test_project

Проверка интерфейса использует настоящее окно Tkinter и вызывает
Windows PlaySound на короткое время. Запускайте её в интерактивном
сеансе Windows. Тесты исходников можно запускать без устройства звука:
    python -m unittest -v test_project.EngineTests

СБОРКА EXE НА WINDOWS

    python -m pip install pyinstaller
    python -m PyInstaller --noconfirm --onefile --windowed --name RNGMelodyCreator main.py

Запустите dist\RNGMelodyCreator.exe. PyInstaller нужен только для
сборки. Текстовые файлы можно приложить к EXE отдельно.
https://pyinstaller.org/en/stable/usage.html

ФАЙЛЫ

main.py                         Окно, кнопки и фоновая генерация.
generators.py                   Три источника случайности.
music_theory.py                 Гаммы, интервалы, матрица, частоты.
melody.py                       Мотив, высоты, ритм и завершение.
audio.py                        Синтез, WAV, копирование и звук.
statistics_report.py            Расчёт и окно статистики.
test_project.py                 Проверки модели, WAV и интерфейса.
requirements.txt                Внешних зависимостей для запуска нет.
STATISTICS_AND_MUSIC_THEORY.txt  Суть программы, алгоритм и источники.
