RNG Melody Creator

Программа для Windows, которая сочиняет короткие мелодии.
Можно послушать результат и сохранить понравившуюся мелодию.

Как скачать и запустить

1. Откройте страницу релиза.
   https://github.com/letniyhash/rng-melody-creator/releases/latest
2. В разделе Assets скачайте RNGMelodyCreator.exe.
3. Откройте скачанный файл двойным щелчком. Установка не нужна.

В программе выберите длительность и нажмите «Сгенерировать мелодию».
Если результат понравился, нажмите «Сохранить WAV».
